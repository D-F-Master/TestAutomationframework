# 接口测试用例格式规范（Excel 模板）

## 一、字段说明

| 序号 | 列名             | 字段含义                     | 填写规则与示例                                                                 |
|------|------------------|------------------------------|--------------------------------------------------------------------------------|
| 1    | **编号**         | 用例唯一标识                 | - 必填<br>- 建议数字或 `模块_序号`，如 `100`, `login_01`<br>- 不可重复        |
| 2    | **模块**         | 所属功能模块                 | - 必填<br>- 如：`登录`、`绿植`、`文件上传`                                     |
| 3    | **场景**         | 测试场景描述                 | - 必填<br>- 简洁说明测试目的，如：`登录成功`、`无权限访问`、`路径参数校验`     |
| 4    | **标题**         | 用例标题                     | - 必填<br>- 与“场景”类似，可相同，用于展示                                   |
| 5    | **请求方式**     | HTTP 方法                    | - 必填<br>- 大写：`GET` / `POST` / `PUT` / `DELETE` 等                        |
| 6    | **路径**         | 接口路径（支持变量）         | - 必填<br>- 支持变量占位符：`/admin/plant/{{PLANT_ID}}`<br>- 变量需在“json提取”或前置用例中定义 |
| 7    | **请求头**       | Headers                      | - 可选<br>- 格式：`{"key": "value"}` 或多行键值对<br>- 示例：<br>  `{"token": "{{TOKEN}}"}`<br>  `Content-Type: application/json` |
| 8    | **url参数**      | Query / Path 参数            | - 可选<br>- 格式：`{"id": 1, "page": 1}`<br>- 若为 path 参数，路径中需有对应占位符 |
| 9    | **data参数**     | 表单数据（x-www-form-urlencoded） | - 可选<br>- 格式：`{"username": "admin", "password": "123"}`                  |
| 10   | **json参数**     | JSON 请求体                  | - 可选<br>- 必须是合法 JSON 字符串<br>- 示例：<br>  `{"name": "花盆", "price": 10}`<br>- 支持换行格式（Excel 单元格内按 Alt+Enter） |
| 11   | **文件参数**     | 文件上传字段                 | - 可选<br>- 格式（Python requests 风格）：<br>  `{'file': ('1.png', open('./img.png','rb'), 'image/png')}`<br>- 实际执行时需替换为真实文件路径 |
| 12   | **校验字段**     | 响应中需校验的 JSONPath       | - 可选<br>- 支持单个或多个（逗号分隔或换行）<br>- 示例：<br>  `$.code`<br>  `$..name`<br>  `['$.code', '$.msg']` |
| 13   | **预期结果**     | 对应校验字段的期望值         | - 可选<br>- 与“校验字段”一一对应<br>- 示例：<br>  `1`<br>  `小叶栀子花盆栽`<br>  `[200, "success"]` |
| 14   | **数据库校验内容** | SQL 查询语句（用于断言）     | - 可选<br>- 示例：<br>  `select name from employee WHERE username = 'admin'`   |
| 15   | **数据库预期结果** | 数据库查询的期望返回值       | - 可选<br>- 示例：<br>  `管理员`<br>  `1`                                      |
| 16   | **json提取**     | 从响应中提取变量（供后续用例使用） | - 可选<br>- 格式：JSON 对象，key=变量名，value=JSONPath<br>- 示例：<br>  `{"TOKEN": "$..token"}`<br>  `{"PLANT_ID": "$.data.id"}` |
| 17   | **sql提取**      | 从数据库提取变量             | - 可选<br>- 格式：JSON 对象，key=变量名，value=SQL<br>- 示例：<br>  `{"USER_ID": "select id from user where name='admin'"}` |
| 18   | **是否执行**     | 控制用例是否运行             | - 必填<br>- 仅允许：`TRUE` / `FALSE`（建议大写，部分框架区分大小写）         |

## 二、填写规范细则

### ✅ 通用规则
- 所有字段均为**文本格式**（避免 Excel 自动转为数字/日期）。
- 支持**换行**（在 Excel 中按 `Alt + Enter`），适用于多参数或多校验点。
- **变量占位符**格式：`{{VARIABLE_NAME}}`，如 `{{TOKEN}}`、`{{PLANT_ID}}`。
- **JSON 必须合法**：建议用双引号，必要时转义（如嵌套 JSON 字符串需用 `""` 表示 `"`）。

### 🔁 变量传递机制
- **前置用例**通过 `json提取` 或 `sql提取` 定义变量。
- **后续用例**可在 `路径`、`请求头`、`url参数`、`json参数` 等字段中引用：`{{TOKEN}}`。
- 示例：
  ```excel
  json提取: {"TOKEN": "$..token"}
  请求头: {"Authorization": "Bearer {{TOKEN}}"}
  ```

### 📌 特殊字段说明

#### ▶ json参数（重要）
- 若内容为多行 JSON，建议在 Excel 中手动换行，或写成单行：
  ```json
  {"name": "", "category": "", "page": 1, "pageSize": 10}
  ```
- **不要加 Python 字典前缀**（如 `dict(...)`），必须是纯 JSON 字符串。

#### ▶ 文件参数
- 仅用于支持文件上传的自动化框架（如基于 `requests` 的脚本）。
- 实际执行时需确保文件路径存在。

#### ▶ 校验字段 & 预期结果
- 支持**单值**或**列表**：
  - 单值：`$.code` → `1`
  - 多值：`['$.code', '$.msg']` → `[1, "success"]`
- 若只校验状态码，可留空此字段，由框架默认校验 HTTP 状态。

## 四、推荐使用流程

1. **自动生成**：用 Swagger 脚本导出基础用例（填充编号、模块、路径、方法等）。
2. **人工补充**：测试人员填写“场景”、“校验字段”、“预期结果”、“是否执行”等。
3. **变量串联**：通过 `json提取` 实现登录态、ID 等跨用例传递。
4. **自动化执行**：使用兼容此模板的测试框架（如 pytest + Excel 驱动）。
